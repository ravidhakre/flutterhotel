# ADMIN USER OPERATIONS MANUAL

## 1. Executive Control Portal Overview
The Administrative Control Portal provides full operational and commercial management for Flutter Hotels & Resorts.

---

## 2. Key Modules
- **Front Desk Operations**: Manage Today's Arrivals, Departures, Currently In-House guests, Check-in, and Check-out.
- **Reservations Center**: View, filter, and assign physical rooms to reservations.
- **Promotional Offers & Coupons**: Create discount campaigns, set priority stacking rules, and coupon codes with usage limits.
- **Pricing Simulator**: Test date ranges, extra guest charges, and GST tax breakdowns.
- **Payment Transactions & Refunds**: View transaction ledgers, process full/partial refunds, and run reconciliation audits.
- **Executive Analytics**: Real-time ADR, RevPAR, Occupancy %, GBV, and Net Revenue dashboards.
- **Content Management System (CMS)**: Manage homepage hero banners, FAQs, and versioned legal policies.
- **Reports Center**: Export bookings and payments to CSV files.
